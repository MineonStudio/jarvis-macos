# Meeting test audio

`AMI-ES2002a-Mix-Headset.wav` is the mixed-headset signal from the official AMI Meeting Corpus, meeting `ES2002a`.

- Format: 16 kHz, 16-bit, mono WAV
- Duration: about 21 minutes 13 seconds
- Language: English
- Source: <https://groups.inf.ed.ac.uk/ami/AMICorpusMirror/amicorpus/ES2002a/audio/ES2002a.Mix-Headset.wav>
- Corpus/license information: <https://groups.inf.ed.ac.uk/ami/download/> (CC BY 4.0)

Use it to exercise the meeting import/transcription path and speaker diarization. It is an English sample, so the current Chinese Paraformer path may not produce useful English words; it remains useful for validating audio loading, timing, speaker segmentation, and failure handling.

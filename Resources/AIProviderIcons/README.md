# API 提供商图标

提供商胶囊使用本地品牌图标；新增可选提供商时，请同时添加品牌资源并在 `AIAPIProvider.brandIconResource` 中登记。`custom` 是自定义接口入口，不代表第三方品牌，因此保留通用设置图标。
